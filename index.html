01 — About

My path here wasn't a straight line: dental surgery, then a Master's in Health Informatics, then two clinical data coordinator roles before landing in a neuroscience lab building imaging pipelines for NIH-funded Alzheimer's research.

That order matters more than it looks like it should. Clinical training taught me what a data point actually costs to collect, and what it means when it's wrong. Now I spend my days writing Python and Bash that turn hundreds of raw microscopy images or MRI scans into analysis-ready, reproducible output — and structured clinical data management (REDCap, Cerner, OnCore) that has to hold up under audit. I care less about being the most technically clever person in the room and more about whether the person who inherits my pipeline six months from now can actually run it.

02 — Selected work

Pipelines I've built and run in production.

Python · Imaris XT · Fiji/ImageJ — Fluorescence microscopy

Multi-channel fluorescence microscopy pipeline (KOOB)

A four-combination antibody/region imaging workflow that used to require manual channel compositing, ROI definition, and marker quantification for every single image. I scripted the full workflow end-to-end — mask, colocalize, detect surfaces — as a modular pipeline with per-batch CSV logging and skip-completed logic, so a failed run picks up where it left off instead of starting over.

  • 216 images processed in batches of ~50, ~12 minutes per image, unattended overnight
  • Threshold tuning validated against known colocalization patterns before rollout

Python · YAML config — Adopted as lab standard

Amyloid-beta uptake quantification pipeline

Built from scratch as a config-driven pipeline rather than a one-off script: a YAML file defines the study, and the same code runs colocalization and masking logic against it. That decision paid off almost immediately — the pipeline is now the lab's standard approach for amyloid-beta uptake analysis, used by people who never touched the code that built it.

  • Config-per-study design means new experiments don't require new code
  • Caught and fixed a masking logic bug before it reached published results

FSL · ANTs · PALM · SLURM/HPC — Neuroimaging

Voxel-based morphometry pipeline for a rodent AD model

Structural MRI analysis of brain volume across age, diet, and sex in a rodent Alzheimer's model — DICOM-to-NIfTI conversion, ANTs registration, FSL/ITK-SNAP segmentation, and PALM statistical modeling, orchestrated and monitored as SLURM array jobs on IU's HPC cluster. I extended an existing pipeline framework rather than starting from zero, which meant learning to debug someone else's architecture under a live study deadline.

  • Standardized, reproducible outputs across a multi-cohort, multi-subject dataset
  • Built an HTML mosaic reporting tool (nibabel/matplotlib) for fast visual QC

Python · dcm2niix · Bash — Longitudinal data pipeline

LOAD3 longitudinal MRI data pipeline

A longitudinal imaging study means the same data-wrangling problem repeated across cohorts, diets, sexes, and timepoints — with every spreadsheet export threatening to mangle a microchip ID into scientific notation. I built a CSV-driven pipeline that converts DICOM to NIfTI, renames files against a source-of-truth naming spreadsheet, and audits for scan series that don't match convention instead of silently skipping them.

  • CSV-driven design avoids picking up stray or leftover scan series
  • Built-in audit step flags mismatched files for manual review instead of failing silently

Power BI · REDCap · Cerner · OnCore — Clinical data & reporting

Clinical data management & institutional reporting

Before pipelines, there's the less glamorous work of making sure the data is right in the first place. I managed clinical research data across REDCap, Cerner, and OnCore for NIH-funded hepatology studies under GCP and IRB standards, and separately built Power BI dashboards supporting leadership decisions across 100+ residency and fellowship programs.

  • Source data verification and HIPAA-compliant handling for active clinical trials
  • Recognized with a Student Employee of the Year nomination for reporting reliability
